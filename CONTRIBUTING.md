# Contributing

Open an issue or pull request with the original URL, creator, a short neutral description, evidence connecting it to Claude Fable 5.2, and any prompt, code or demo link. Mention whether you tested the artifact and when; provide a timestamp and source for any popularity metric. Disclose relevant commercial ties. Avoid affiliate links, unsourced performance claims, copied media, and credentials. Maintainers may edit or decline entries and welcome corrections or removal requests.
