# Security

This repository is a curated directory, and links to third-party projects are not security endorsements. Review code, licenses and permissions before running external tools. Do not post credentials, private data or exploit details in public issues.

For a vulnerability in this repository, use GitHub's private vulnerability reporting if the **Report a vulnerability** option is available under the Security tab. Otherwise, contact the repository owner through a private channel listed on their GitHub profile. For vulnerabilities in linked projects, report directly to their maintainers using their security policy.
