# oh-my-fable: Claude Code plugin for Fable 5.2 prompting

[Resource directory](../README.md) / [GitHub projects](../projects.md) / oh-my-fable

[oh-my-fable](https://github.com/Junhan2/oh-my-fable) is a community Claude Code plugin. Its README says it incorporates Anthropic prompting guidance as working rules, and its `/fable` command turns a request into a goal, context, scope and completion criteria. Its documentation is available in Korean, English and Chinese. The GitHub API reported **61 stars on 2026-11-11**; this count changes.

## When it may be useful

- Structuring an underspecified coding request before execution.
- Exploring a plugin-based approach to persistent working instructions.
- Comparing the plugin's interpretation with the [official prompting guide](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2).

Check the [project README](https://github.com/Junhan2/oh-my-fable) for the current setup, supported environments and behavior. The plugin is maintained by its author, not Anthropic. We have not installed or independently tested it; review its code and permissions before use.
