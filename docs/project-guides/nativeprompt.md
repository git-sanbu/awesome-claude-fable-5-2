# nativeprompt for Claude Fable 5.2: prompt and instruction review

[Resource directory](../README.md) / [GitHub projects](../projects.md) / nativeprompt

[nativeprompt](https://github.com/edvardgrishin27/nativeprompt) is a community tool whose GitHub description says it reviews prompts and instruction files such as `CLAUDE.md`, `AGENTS.md` and skills against model-specific vendor guidance, including Claude Fable 5.2. Its author describes it as offline and dependency-free. The project listed **128 stars on 2026-11-11**; this is a snapshot, not a measure of growth.

## When it may be useful

- Reviewing a project instruction file for alignment with the model guidance cited by the tool.
- Exploring vendor-documented prompting patterns before revising a prompt.
- Comparing how a tool represents guidance for multiple models.

Read the [project README](https://github.com/edvardgrishin27/nativeprompt) for current installation, supported models and usage. Inspect the source and permissions before running third-party tools. We have not independently installed or evaluated it, and its recommendations are not a substitute for checking [Anthropic's official Fable 5.2 guide](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2).
