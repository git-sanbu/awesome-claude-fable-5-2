## Model facts

Condensed from the launch announcement and platform docs on 2026-11-11; benchmark and demonstration numbers are vendor-reported as of launch day, not independently verified.

- Claude Fable 5.2 and Claude Mythos 5.2 were announced on November 9, 2026 (per the page's published-time metadata and the Anthropic newsroom index) — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- Fable 5.2 and Mythos 5.2 are the same underlying model: Fable adds cybersecurity and biology safeguards and is available to all users, while Mythos is restricted to organizations vetted through the Cyber Verification Program or Life Sciences Verification Program — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- Family positioning per Anthropic: Fable/Mythos are for the most ambitious open-ended technical work; for most coding and knowledge tasks Anthropic recommends starting with Claude Opus 5.5 and stepping down to Sonnet 5.5 or Haiku 5.5, with Fable 5.2 also able to act as an Advisor (consulted by smaller models) or Orchestrator (delegating to smaller models) — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- Specs: a 1M-token context window (both default and maximum) and 128k max output tokens, the tokenizer introduced with Claude Opus 4.7, and adaptive thinking always on with the `effort` parameter controlling thinking depth — [What's new docs](https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2).
- Pricing (USD): $8 per million input tokens and $40 per million output tokens, down from $10/$50 on Fable/Mythos 5.1; cache reads cost 0.025x base input, and batch processing is $4/$20 per million tokens — [What's new docs](https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2).
- Optional fast mode speeds up token generation by up to 2.5x at $16/$80 per million tokens, available on Claude Code, the Claude Platform (Messages API), Claude Models on Google Cloud and Microsoft Foundry — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2); on Anthropic-hosted deployments fast mode is the separate model `claude-fable-5-2-fast` — [What's new docs](https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2). Mythos fast mode is limited to Verification Program members — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- Vendor-reported as of launch: outputs up to 30% faster than Fable/Mythos 5.1, and on the FrontierCode 2.0 evaluation Fable 5.2 at High effort scored about level with Opus 5.5 at Max effort for roughly half the cost per task, with the highest score of any released model tested at Xhigh effort — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- The API default effort for Fable 5.2 is `high`; `medium` is the default in Claude apps and Claude Code — [What's new docs](https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2).
- Prerelease demonstrations reported by Anthropic (company-reported, not independently verified): 1,000 Fable 5.2 agents fully formalized Fermat's Last Theorem in 30 hours with minimal human intervention (an earlier unreleased research version took 11 days; Opus 5.5 with the same setup completed 26% in 18 hours); it solved two open problems in black-hole physics; designed three working electronic devices with manufacturer Diode; a team of agents running an earlier (prerelease) version of Fable 5.2 migrated a production service from Python to Rust that now starts about 26x faster; and coordinated 1,000+ subagents over eight days to build a bootable prototype operating system — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- On Anthropic's internal CVE Rediscovery evaluation, Mythos 5.2 found 10.2% more vulnerabilities than Opus 5.5 and 14.4% more than Mythos 5.1, and a security tester found previous models overstated roughly 1 in 20 findings while Mythos 5.2 overstated none; note that Fable 5.2's safeguards block most cybersecurity tasks — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- Fable 5.2's cyber/bio safeguard classifiers produce about 55% fewer blocks than Fable 5.1 in Anthropic's early testing (about 60% fewer in cybersecurity, 40% fewer in biology); blocked queries are answered by Opus 4.8 for cybersecurity and Opus 5 for biology as the permitted fallback targets — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- Anthropic states Fable 5.2 has its strongest-ever protections against distillation attacks (reported 90-99% reduction in harvested data), and that preserved thinking now applies to all API accounts — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- During training Anthropic limited capabilities that would most directly accelerate AI development: in areas like accelerator kernel optimization and LLM architecture improvement, Fable/Mythos 5.2 perform at about the level of Opus 5.5, with transparent fallbacks to Opus 5 for a small set of topics (e.g. kernel development on certain nonstandard accelerators) — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- Four breaking changes vs Fable 5.1: the preserved-thinking prefix check applies to every account; only Fable 5.2 and Mythos 5.2 can read Fable 5.2 thinking blocks; the `computer_20251124` computer-use tool returns an error on every platform except Amazon Bedrock; and a Fable 5.2 executor in the beta advisor tool requires a Fable 5.2 or Mythos 5.2 advisor — [What's new docs](https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2).
- Messages API rules: `thinking {"type": "enabled"}` with `budget_tokens` and `{"type": "disabled"}` both return 400 (adaptive thinking is the only mode), and forced tool use (`tool_choice {"type": "any"}` or `{"type": "tool"}`) returns 400; use strict tool use or JSON outputs instead (structured outputs are unavailable under customer-managed encryption keys) — [What's new docs](https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2).
- Availability: `claude-fable-5-2` for all Claude API customers; `anthropic.claude-fable-5-2` on Amazon Bedrock; `claude-fable-5-2` on Claude Platform on AWS and Claude Models on Google Cloud (Anthropic and Google managed) and on Microsoft Foundry (Anthropic-hosted); Mythos 5.2 (`claude-mythos-5-2`) is limited to verified organizations — [What's new docs](https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2).
- Fable 5.2 and Mythos 5.2 require 30-day data retention and are not available under zero data retention unless expressly authorized by Anthropic (Enterprise Frontier Safeguards, in private beta with customers including Bridgewater, Salesforce and Stripe, offers ZDR-compatible safety monitoring); both are Covered Models — [What's new docs](https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2).
- Predeployment external evaluators included the UK AI Security Institute, Frontier Design and METR, and a "Claude Fable 5.2 and Mythos 5.2 System Card" was published — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- Anthropic states that over 90% of changes merged into its core codebase are now written by Claude with human guidance, as of the Fable 5.2 launch post — [launch announcement](https://www.anthropic.com/claude-fable-and-mythos-5-2).
- As of Nov 11, 2026, the Anthropic newsroom lists no separate Fable 5.2 model-card, system-prompt or Claude Code announcements; the Nov 9, 2026 launch post is the only Fable 5.2 item — [Anthropic Newsroom](https://www.anthropic.com/news).

Availability, pricing and features change; treat this page as a verified snapshot from 2026-11-11 and check the linked pages before relying on a number. Back to the [resource directory](README.md).
