A curated snapshot of 48 repositories found via catalogue mining, X tracing and GitHub search; star counts are a GitHub API snapshot as of **2026-11-11**. Stars are point-in-time counts, not growth rates; listed functionality and model attribution are from maintainers and were not independently tested. Inclusion does not imply an audit or endorsement.

## Playable demos from viral posts

Some launch-week demos live outside GitHub — play them first, then read the code:

- [Saltline](https://claude.ai/artifact/BGY1SztrAYcJQHSsnHHGmp) - Felix Rieseberg's single-prompt browser FPS, playable as the original Claude artifact (may require sign-in); no official repo exists, so every GitHub Saltline below is a third-party restoration or mirror.
- [Portals: Endless Worlds](https://portals-endless-worlds.netlify.app) - an endless flight through 450+ agent-built code-only worlds; source is open at [emollick/ai-portals](https://github.com/emollick/ai-portals) in the table below.
